# 🌱 測測你的「2050 永續公民屬性」！ (Sustainability Citizen Quiz)

> **《永續公民實踐》期中創意作業專案**  
> 設計者：林世偉 | 班別：下午B班

---

## 🌟 專案簡介
距離 2050 年僅剩 24 年。本專案以時下熱門的 **MBTI / 台灣設計展心理測驗互動形式**，將《永續公民實踐》課堂上的四大核心概念轉化為 6 道情境測驗題與 4 種專屬永續性格光譜：

1. **🏛️ 澄毓系·低碳築境師**（EEWH 綠建築九大指標、SC 鋼構減碳 29%、雨水回收水循環）
2. **🦅 翱翔者·生態守護鳥**（離岸風電 1,315 公尺鳥類遠距監測、生態衝擊減輕四部曲：避免/最小化/復育/抵換）
3. **⚖️ 仲裁者·ESG 人權法官**（國家人權委員會、巴黎原則、供應鏈盡職調查、破除紙吸管漂綠迷思）
4. **🚀 未來人·2050 逆轉先鋒**（IPCC AR6 跨世代氣候變遷曲線、碳盤查與碳有價時代、跨專業整合實踐）

---

## 📱 跨載具響應式優化（Responsive Design）
- **手機端（Mobile）**：流暢單手拇指操作、大尺寸卡片點擊、觸控震動反饋（Haptic Feedback）、全螢幕最適比例。
- **平板端（Tablet）**：置中舒適閱讀寬度、雙欄卡片佈局。
- **電腦端（Desktop）**：精緻 Hover 微交互、支援鍵盤 `1`～`4` 或 `A`～`D` 快捷鍵迅速答題。
- **📸 拍立得卡片一鍵下載**：內建 HTML5 Canvas 繪圖引擎，測驗完可直接匯出專屬高畫質分享卡（PNG），方便發 IG 限動或列印繳交。
- **📊 5 維動態雷達圖**：即時計算個人在「減碳實力、空間工法、生態感知、政策敏銳、行動爆發」之光譜分佈。

## 🚀 線上即時體驗
本專案採用純原生 HTML5 + Tailwind CSS + Web Audio API + Canvas API，無需任何伺服器環境或複雜建置，雙擊 `index.html` 即可在任何瀏覽器離線暢玩。
